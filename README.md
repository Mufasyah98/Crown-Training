## 🎯 Programme outcomes

By the end of this programme, participants should be able to:
1. Explain how Microsoft 365 services connect through identities, permissions, storage and applications.
2. Choose between OneDrive and SharePoint, share securely, co-author, and restore file versions.
3. Create Teams collaboration spaces and manage email-to-task workflows.
4. Collect structured information using Forms and Lists.
5. Connect Excel data to Word and PowerPoint reports; consolidate files with Power Query.
6. Build and test basic Power Automate approval and reminder flows.
7. Apply appropriate information sharing and data governance practices.

## ✅ Before training

**Required:** Microsoft 365 work/school account, access to desktop Excel/Word/PowerPoint/Outlook and Teams, browser, stable internet, and MFA device where needed. Ask the training coordinator or IT team to confirm access to SharePoint, OneDrive, Forms, Lists, Planner and Power Automate. **Some exercises require creation rights or configured tenant settings.**

1. Check the [Microsoft 365 home](https://www.microsoft365.com/) and sign in with your **work or school account**.
2. Read [Microsoft 365 training](https://support.microsoft.com/en-us/training) for product fundamentals.
3. Review [Microsoft Learn — Microsoft 365 documentation](https://learn.microsoft.com/en-us/microsoft-365/) for the official platform overview.
4. Open the apps you will practise with before arriving; confirm edit/create permissions, not just view access.
5. Use **fictional/synthetic data** in activities. Do not place genuine employee, applicant or customer personal data in practice forms, flows, screenshots or public repositories.
6. Record your **three biggest recurring workplace process problems** to use in the Workflow Audit Canvas.

**Suggested working structure (create locally or inside an approved training site):** `Day1/`, `Day2/`, `NovaTrade/`, `Outputs/`. This is a recommendation, **not** a claim these folders or sample files already exist in GitHub.

## 🌟 Day 1: Foundation and collaboration

### Module 1 🧠 — Microsoft 365 ecosystem and application integration
**9:00–9:45 AM**

**Learn:** shared identity (Microsoft Entra ID), Microsoft Graph at a conceptual level, app/data relationships, desktop vs web experiences, licences and common integration failures.

**📚 Official references — click to open**
- [Microsoft 365 documentation](https://learn.microsoft.com/en-us/microsoft-365/)
- [Microsoft Entra documentation](https://learn.microsoft.com/en-us/entra/)
- [Microsoft Graph overview](https://learn.microsoft.com/en-us/graph/overview)
- [Microsoft 365 training hub](https://support.microsoft.com/en-us/training)

**🛠️ Guided activity — Workflow Audit Canvas**
1. Choose a monthly workflow (expense claim, leave request or branch report).
2. Diagram inputs, people, handoffs, storage locations and approvals.
3. Mark attachments, repeated data entry, follow-up messages and version duplication.
4. Propose three improvements using Microsoft 365 applications.

**✅ Expected output:** current-state workflow and three integration opportunities.

### Module 2 ☁️ — OneDrive and SharePoint: cloud storage, sharing and version control
**9:45–11:00 AM**

**Learn:** OneDrive vs team-owned SharePoint libraries, sync and Files On-Demand, sharing scopes, view/edit access, version history, recycle bin, co-authoring and metadata.

**📚 Official references — click to open**
- [OneDrive help and learning](https://support.microsoft.com/en-us/onedrive)
- [SharePoint help and learning](https://support.microsoft.com/en-us/sharepoint)
- [SharePoint documentation](https://learn.microsoft.com/en-us/sharepoint/)
- [OneDrive documentation](https://learn.microsoft.com/en-us/sharepoint/onedrive-overview)

**🛠️ Guided lab — Departmental document library**
1. In an **approved SharePoint site**, create or use a document library.
2. Add metadata columns: **Department**, **Document Type**, **Review Date**.
3. Upload **sample** documents and populate the metadata.
4. Create a filtered view for documents due for review.
5. Review sharing permissions and choose the least permissive suitable scope.
6. Co-author a Word file, edit it multiple times, and inspect version history.
7. Restore an earlier version using the available options.

**✅ Expected output:** structured library, filtered view, safely shared file and restored version.

**Decision rule:** OneDrive for individual working files; SharePoint for department/team-owned files requiring shared governance.

## ⚡ Day 2: Integration automation and governance

### Module 6 📊 — Cross-application document workflows: Word, Excel and PowerPoint
**9:00–10:00 AM**

**Learn:** Word Styles/TOC/captions, Excel-linked tables/charts, embedded vs linked objects, Word Mail Merge, PowerPoint Slide Master/templates, document accessibility and PDF export.

**📚 Official references — click to open**
- [Word help and training](https://support.microsoft.com/en-us/word)
- [Excel help and training](https://support.microsoft.com/en-us/excel)
- [PowerPoint help and training](https://support.microsoft.com/en-us/powerpoint)
- [Microsoft 365 accessibility](https://www.microsoft.com/en-us/accessibility/microsoft-365)

**🛠️ Guided lab — Monthly management pack**
1. Prepare a small structured Excel summary and chart.
2. Create a Word management report using Styles and headings.
3. Link (not merely paste as an image) the relevant Excel content into Word/PowerPoint using supported **desktop app** functionality.
4. Change figures in the Excel source and test how linked content is updated.
5. Prepare a Mail Merge letter for ten **fictional** recipients.
6. Export the approved report for circulation.

**✅ Expected output:** Excel source, Word report, PowerPoint slide and mail-merge sample.

**Caution:** Web and desktop experiences differ; embedded objects and linked content may require the desktop application and a valid source path. Validate updates before presenting numbers as current.

### Module 7 🟢 — Excel in Microsoft 365 and Power Query
**10:00–11:00 AM**

**Learn:** structured Tables, co-authoring, SharePoint folder connections, cleaning/data types, append vs merge, PivotTables, refresh and validation.

**📚 Official references — click to open**
- [Excel training](https://support.microsoft.com/en-us/excel)
- [Power Query documentation](https://learn.microsoft.com/en-us/power-query/)
- [Power Query SharePoint folder connector](https://learn.microsoft.com/en-us/power-query/connectors/sharepoint-folder)

**🛠️ Guided lab — Refreshable branch report**
1. Store three **synthetic** branch files in a permitted SharePoint folder.
2. Connect from **Excel desktop Power Query** to the approved source.
3. Transform headings and data types; remove duplicates if justified.
4. Append compatible monthly files and merge lookup data where needed.
5. Load the result and create a PivotTable by region/product category.
6. Add a fourth period file, refresh and verify totals against the sources.

**✅ Expected output:** refreshable consolidated table and PivotTable report.

**Quality check:** Do not silently guess whether discounts are gross or net; document uncertainties and escalate them.

### Break — 11:00–11:15 AM

### Module 8 🔁 — Power Automate: routine workflow automation
**11:15 AM–12:30 PM**

**Learn:** automated/instant/scheduled cloud flows, triggers, actions, conditions, dynamic content, approvals, run history, failure handling and ownership.

**📚 Official references — click to open**
- [Power Automate documentation](https://learn.microsoft.com/en-us/power-automate/)
- [Power Automate training](https://learn.microsoft.com/en-us/training/powerplatform/power-automate)
- [Microsoft Forms connector](https://learn.microsoft.com/en-us/connectors/microsoftforms/)
- [SharePoint connector](https://learn.microsoft.com/en-us/connectors/sharepointonline/)
- [Approvals in Power Automate](https://learn.microsoft.com/en-us/power-automate/approvals-overview)

**🛠️ Guided lab A — Request approval**
1. Start from a Forms submission with a **new response** trigger.
2. Retrieve response details; send an approval request to the designated approver.
3. Add an outcome condition (Approved/Rejected).
4. Create or update the corresponding List item.
5. Notify the requester with an appropriate message.
6. Run approved and rejected test cases; inspect the flow's run history.

**🛠️ Guided lab B — Scheduled reminder**
1. Create a scheduled flow (e.g., Mondays).
2. Retrieve relevant Planner tasks where tenant capabilities permit.
3. Identify overdue and incomplete tasks.
4. Send a summary email; handle empty task lists and failures.

**✅ Expected output:** tested approval prototype and scheduled reminder prototype.

**Caution:** Available connectors, action names, permissions and licence entitlements vary by tenant. Avoid premium-only features in the core lab; consult IT if a connector/action is blocked.

### Module 9 🛡️ — Microsoft 365 security, governance and PDPA awareness
**1:30–2:45 PM**

**Learn:** MFA, sensitivity labels (where configured), link/guest permissions, site ownership, retention, auditing, personal data handling, and departmental governance.

**📚 Official references — click to open**
- [Microsoft 365 security documentation](https://learn.microsoft.com/en-us/microsoft-365/security/)

**🛠️ Guided lab — Sharing and permission audit**
1. Review a **training** SharePoint site and identify excessive access.

3. Remove or narrow inappropriate sharing permissions where authorised.
4. Inspect available classification or sensitivity labels.
5. Complete a one-page governance checklist: **naming, owner, access, retention, personal data, review frequency**.

**✅ Expected output:** documented governance review and remediation recommendations.

**Important:** A normal end user may not be permitted to change organisation-wide policies, retention configurations or audit settings. Discuss these controls without attempting administrator-only steps. PDPA topics are training guidance, **not legal advice**; follow your organisation's policies and applicable law.

## 🏆 Capstone: NovaTrade Sdn Bhd
**Day 2, 3:00–4:30 PM**

**Scenario:** NovaTrade is a fictional Malaysian FMCG distributor with branches in **Shah Alam, Penang, and Johor Bahru**. Monthly sales spreadsheets are emailed to HQ, manually consolidated, chased by messaging apps and recirculated as inconsistent management report copies. The existing process takes roughly **two working days per month**.

### Team challenge
Build a **prototype** using approved training services:
1. SharePoint library with submission metadata and appropriate access design.
2. Forms submission and Lists tracking.
3. Power Automate notification/exception approval.
4. Excel Power Query consolidation and PivotTable summary.
5. Linked Word/PowerPoint management pack.
6. Teams workspace for branch/HQ collaboration.
7. Governance choices for sensitive information.

### Planted data-quality and privacy issues
- **Penang:** different column headings — standardise with documented mappings.
- **Johor Bahru:** duplicated transactions — verify a suitable deduplication rule.
- **Shah Alam:** unclear gross/net discount basis — **do not guess**; flag for clarification.
- **Customer contact list:** personal information shared by uncontrolled attachment — restrict access, avoid using genuine data in demonstrations and document a safer process.

### Session plan

| Stage | Duration | Expected evidence |
|---|---:|---|
| Scenario briefing | 10 min | Shared understanding |
| Solution design | 15 min | Diagram, owners, governance decisions |
| Prototype build | 40 min | Working demonstration |
| Team presentation | 20 min | Business explanation and evidence |
| Debrief | 5 min | Lessons, risks and improvements |

**Assessment:** technical correctness, integration architecture, data-quality decisions, governance and communication to non-technical management.

## 🧰 Troubleshooting and access

| Issue | First check | Next step |
|---|---|---|
| Cannot create Team/site/List | Organisation permissions | Ask trainer/IT for an approved training workspace |
| Forms/Planner/Power Automate unavailable | Signed-in work account, app enablement and licence | Confirm tenant policy with IT |
| SharePoint folder Power Query error | Source URL, authentication and file structure | Check connector guidance and sample file consistency |
| Linked chart does not update | Linked vs embedded object, desktop vs web and source location | Reopen source, update links and verify figures |
| Flow fails | Connection authorisation, required fields and run history | Read the failing action and test again with synthetic records |
| Label or sharing option missing | Tenant policy, sensitivity configuration and user permission | Demonstrate concept, do not bypass organisational controls |

## 🎯 After training
